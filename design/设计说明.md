# 任务管理系统设计说明

该 ToDo 管理系统采用 Python + Django 开发，使用 SQLite 作为演示环境数据库，项目结构遵循 Django 应用分层原则：models.py 负责数据模型定义，forms.py 负责表单与后端验证，views.py 实现业务逻辑并处理请求，templates 提供页面展示。核心模型 Task 包含标题、描述、状态、优先级与截止日期，并保存创建/更新时间。表单层对输入进行校验（如标题必填、截止日期不能早于当天），保证数据一致性。列表页实现了状态与优先级筛选、关键词搜索、分页以及统计（总数/已完成/未完成），便于用户查看与管理。导出功能通过 openpyxl 将当前筛选结果导出为 XLSX 文件，便于备份与分析。页面使用 Bootstrap CDN 提供简洁易用的交互界面。此设计便于扩展（如添加用户认证、标签、提醒、API 支持），代码结构清晰、注释详细，方便交付与维护。
