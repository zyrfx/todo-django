# Release v1.0 - ToDo 管理系统（todo-django）

发布内容：
- 完整源码（请在仓库页面下载 ZIP 或 clone）：https://github.com/zyrfx/todo-django
- 设计说明 PPT（占位）：/design/todo-design.pptx-placeholder.txt
- 占位截图（可替换）：/assets/screenshots/placeholder_home.svg, /assets/screenshots/placeholder_form.svg

说明：
- 由于当前环境无法自动运行应用并截取真实屏幕截图，本次 Release 使用占位截图并包含占位 PPT 文本文件。你可以：
  1) 在本地运行应用并截取真实截图（见 README 的运行步骤）；
  2) 将截图文件上传到仓库的 /assets/screenshots/ 目录；
  3) 回复我告诉我截图路径，我会把真实截图插入 PPT 并生成真正的 .pptx 文件并提交。 

如何在 GitHub 页面创建 Release：
1) 进入仓库主页面 https://github.com/zyrfx/todo-django
2) 点击 "Releases" -> "Draft a new release"
3) 填写 Tag version（例如 v1.0）、Title（ToDo 管理系统 v1.0）和描述（拷贝本文件内容）
4) 在 "Attach binaries by dropping them here or selecting them" 区域上传你需要发布的文件（例如：todo-django.zip、design/todo-design.pptx）
5) 点击 "Publish release"

我可以继续协助生成真实的 PPT 和 ZIP 包，或在你上传真实截图后替换占位内容。
